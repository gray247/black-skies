# Orchestrator 9 Ideation Premise Discovery Closure Checkpoint

## 1. Formal Verdict

CLOSE IDEATION / PREMISE DISCOVERY WITH RECORDED CONVERGENCE ITEMS.

Campaign closure means the dossier now has a reconciled and hardened,
implementation-neutral product model.

It does not mean:

- dossier completion
- final cross-dossier validation
- final interface design
- implementation authorization
- runtime, schema, persistence, routing, or model work

## 2. Product Identity

- `Ideation / Premise Discovery` is a governed, author-owned system for
  capturing, exploring, testing, combining, and promoting story
  possibilities.
- Its primary workflow develops an existing fragment.
- It also supports blank-page discovery, premise testing, and idea
  combination.
- It is not an AI story generator, project-truth owner, `Outline`
  owner, `Author Intent / Story Setup` owner, manuscript-critique
  owner, or generic Notes container.

## 3. Owned Model

`Ideation / Premise Discovery` owns:

- `Idea Seeds`
- `Exploration Branches`
- `Premise Versions`
- `Exploration Findings`
- premise-testing state
- idea-combination state
- seed relationships
- global `Idea Library` state
- source-to-promotion provenance

The settled owned-model posture preserves:

- original seed capture
- editable current versions
- explicit branch states
- stale posture after source change
- multiple alternative branches
- promoted history
- archive, recoverable delete, and permanent purge distinctions
- provenance tombstones where descendants survive
- bounded important history

## 4. Exploration Model

- capture is quiet and minimal by default
- `Explore` is explicit
- guided, free, and explicitly AI-assisted modes are all supported
- adaptive questions are allowed
- conversational and worksheet use are both valid
- genre and tone branch lenses remain branch-level exploration posture
- premise testing is optional
- premise testing is evidence-based and advisory
- no overall quality or originality score is produced
- unresolved areas remain visible
- intentional ambiguity may be author-marked
- findings convert only through explicit author action
- combinations preserve source-contribution provenance and allow
  multiple resulting branches

## 5. Surfaces And Assistance

- the full Ideation workspace lives in `Command Center Surface`
- `Writing Surface` provides lightweight `Quick Capture` and
  current-seed access
- `Quick Capture` is available from both surfaces
- tree, list, and comparison views remain non-owning
- `Questions / Unknowns` remains a separate view
- `Needs Review` remains quiet by default
- the system remains fully useful without AI
- `Companion` remains advisory and non-owning
- there is no automatic AI generation, overwrite, promotion,
  conversion, or durable memory creation

## 6. Protection And Recovery

- AI packages include only selected context
- every external request requires a visible preview
- preview posture includes route, purpose, spend, masks, exclusions,
  and approved summaries
- author-versus-AI provenance remains permanent
- protected, excluded, author-only, local-only, and never-send
  boundaries remain enforced
- revealing titles and metadata may be masked
- protected material must not leak through search, summaries,
  comparisons, exports, readiness views, or provenance previews
- missing-source, tombstone, stale, partial-history-loss, and recovery
  posture remain explicit
- failure of AI, Search, indexing, or duplicate detection does not
  block manual ideation

## 7. Promotion And Handoffs

Promotion begins with a reviewed `Promotion Package`.

Promotion supports:

- selective and partial transfer
- later additional promotion
- multiple projects or alternate versions
- unresolved project-premise state
- reference posture
- independent-copy posture
- mixed posture
- one primary owner plus secondary references
- protection-aware consequence preview
- repeat-safe execution
- preserved partial success and explicit retry

Promotion creates candidates or references unless the destination owner
explicitly accepts truth.

Destination ownership remains with:

- `Author Intent / Story Setup`
- `Outline`
- `Story Unit`
- `Narrative Insertion / Narrative Assertion`
- `Character Cards`
- `Lore Cards`
- relationship, timeline, and theme systems
- `Feedback Notes / Revision Resolution` and `Signal Architecture`
- `Memory Lab`

Project changes do not flow back automatically.
