## Breadth findings

### CB-01 — Relationship Map breadth

First-release breadth is underdefined. Mature ceiling is underdefined. Presentation burden must remain controlled.

Provisional recommendation:

* confirmed and candidate relationships
* relationship type and direction
* source references
* confirmed, candidate, conflicted, and stale posture
* basic filtering

Provisional exclusions:

* no graph-owned truth
* no automatic canonization
* no universal relationship taxonomy
* no mandatory numeric confidence score
* no first-release animated history

Mature-ceiling candidate:

Richer multi-entity comparison, history, and evidence disagreement without Character Card or Lore Card ownership.

### CB-02 — Emotion Graph breadth

First-release dimensions remain an author decision. Mature ceiling is underdefined. Dense default presentation is a risk.

Candidate first-release options:

* character emotional state only
* character emotional state plus optional reader-effect target

Preserve:

* observed, planned, accepted, intended, and inferred distinctions
* source visibility
* no emotional-truth ownership
* no fixed psychological doctrine

Mature-ceiling candidate:

Trajectory comparison, multi-character overlays, intended-versus-observed analysis, confidence/history, and optional relationship or pacing overlays.

### CB-03 — Timeline / Pacing / Pressure breadth

Recommendation: Timeline should remain support-only rather than becoming an accepted event-truth owner.

Provisional first-release breadth:

* event references
* chronology comparison
* chronology conflicts
* observed pacing movement
* bounded pressure flags
* planned-versus-observed distinction
* supporting sources

Explicit exclusions:

* no universal pacing score
* no event-truth ownership
* no automatic restructuring
* no interpretation that slow pacing is automatically defective

Mature-ceiling candidate:

Deeper uncertainty, pressure, and pacing analysis while preserving domain ownership.

### CB-04 — Companion useful floor

Companion has an underdefined minimum useful floor and first-release breadth.

Candidate minimum:

* explain surfaced information
* identify source type and owner
* show supporting source
* explain authority status
* route to the real owner
* explain blocked or no-route state

Open author decision:

Whether bounded re-entry help belongs in the minimum floor.

Mature-ceiling candidate:

Bounded investigation, comparison, and guided review without approval, truth, memory, or workflow ownership.

### CB-05 — Command Center first-release boundary

The first-release default inclusion boundary remains underdefined.

Candidate default content:

* blockers
* active Signals
* prepared findings
* pending author decisions

Open author decision:

Whether AI job, route, budget, package, and export state also belong in the default first-release view or remain summonable.

Explicit exclusions:

* no universal dashboard
* no workflow-engine ownership
* no master queue
* no universal ready, approved, complete, or failed state
* no replacement for the Writing Surface

### CB-06 — Search and Retrieval default breadth

Default unified-search breadth remains underdefined.

Candidate source classes:

* manuscript
* outline and planning material
* Character Cards
* Lore Cards
* Notes
* imported source text
* approved memory references

Open author decision:

Whether first-release search is manuscript-first with explicit widening or project-wide by default with source labels and filters.

Preserve:

* retrieval is not memory
* retrieval is not canon
* ranking is not evidence quality
* generated, rejected, historical, and archived material must not silently mix with current material

### CB-07 — Critique result grouping

First-release result grouping remains underdefined.

Provisional recommendation:

* evidence-backed findings
* category
* severity
* confidence or uncertainty
* supporting passage
* concise explanation

Preserve rewrite candidates as a separate explicitly requested action.

Explicit exclusions:

* no universal quality grade
* no critique-owned truth
* no automatic rewrite acceptance
* no hidden grading authority

Mature-ceiling candidate:

Rubrics, comparison history, author preferences, repeated-pattern tracking, and richer evidence bundles without rewrite or truth ownership.

## Approved author-decision record

The author explicitly approved Decisions 1B, 2B, 3B, and 4B. Do not reinterpret or widen these decisions without explicit author direction.

### Decision 1B — Emotion Graph first release

Approved first-release breadth:

* character emotional state
* optional reader-effect target lane
* observed, planned, accepted, intended, and inferred distinctions
* source visibility
* bounded intensity or movement representation

The reader-effect lane must be optional and non-owning.

Preserved exclusions:

* no emotional-truth ownership
* no automatic canonization
* no mandatory universal psychological taxonomy
* no requirement that every project use the reader-effect lane
* no dense default presentation

### Decision 2B — Companion minimum useful floor

Approved minimum:

* explain surfaced information
* identify source type and owner
* show supporting source
* explain authority status
* route to the real owner
* explain blocked or no-route state
* provide bounded re-entry help

Bounded re-entry help may summarize:

* the current project
* the author-visible working location or context
* recent relevant owner state
* unresolved author-visible items
* safe routes back into work

It must not:

* autonomously choose the author's next task
* resolve conflicts
* approve changes
* mutate truth
* become workflow owner
* present hidden background inference as accepted state

### Decision 3B — Command Center first-release default

Approved default content:

* blockers
* active Signals
* prepared findings
* pending author decisions
* AI job and route state
* budget state
* package state
* export state

Preserve a compact, action-oriented default.

Detailed evidence, history, and secondary analytics remain summonable rather than permanently expanded.

Preserved exclusions:

* no universal dashboard
* no master queue ownership
* no workflow-engine ownership
* no universal ready, approved, complete, or failed state
* no replacement for the Writing Surface
* no default wall of analytics

### Decision 4B — Search default breadth

Approved first-release default: project-wide search across the current local project, including:

* manuscript
* outline and planning material
* Character Cards
* Lore Cards
* Notes
* imported source text
* approved memory references

Required:

* strong source-type labels
* source-owner visibility
* easy narrowing and filtering
* current-versus-historical distinction
* explicit treatment of stale or unavailable sources

Generated candidates, rejected material, deleted material, archives, and historical states must not silently mix into ordinary current-project results. They require explicit filters or scopes.

Preserve:

* retrieval is not memory
* retrieval is not canon
* ranking is not evidence quality
* project-wide search does not create universal information ownership
