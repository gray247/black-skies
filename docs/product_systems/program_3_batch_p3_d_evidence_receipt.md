the active manuscript editor immediately writable. The current Project Spine
editor remains the one prose owner. Program 3 presentation does not create a
second editor, manuscript buffer, save owner, or project session.

The central manuscript is no longer presented as one dashboard card among
many. Existing project, recovery, critique, outline, and export capabilities

### 2.2 Four discoverable edge families

Top, left, right, and bottom edges expose one shallow family each:

- top: project actions and export;
- left: manuscript navigation and the current Living Outline presentation;
- right: selected-prose critique and Feedback Notes review support; and
- bottom: bounded session and writing controls.

All four families are closed by default. One edge action opens one support
region; choosing another replaces it rather than stacking nested chrome.
Closing a region returns focus to the edge that opened it. The manuscript
editor remains the same mounted editor throughout open, close, and family
switches.

This batch establishes the shell and disclosure behavior only. The existing
Living Outline controls deliberately remain inside the left family until P3-E
replaces their ordinary form language with the approved direct ecosystem
interaction. The rich critique result deliberately remains inside Writing
support until P3-F moves that presentation into Command Review.

### 2.3 One-action Focus mode

Focus mode removes edge controls and open support in one action without
replacing, remounting, or clearing the editor. Leaving Focus restores the
previous support-family state and preserves manuscript text, selection, dirty
state, and save truth.

### 2.4 Responsive and accessible behavior

The edge controls use semantic buttons, visible labels on hover, keyboard
focus, and expanded state, and named complementary regions. Narrow viewports
overlay support rather than compressing the manuscript below a useful writing
width. Reduced-motion preferences suppress the small shell transitions.

The established dedicated-surface accessibility journey remains green with no
WCAG A/AA axe violations. The shell's semantic viewport evidence verifies the
bounded manuscript measure and responsive support behavior without reviving
the unstable strict full-window snapshot lane.
