## Scope

Stage 6 proves cross-system workflow boundaries before later architecture and implementation planning can be trusted.

The proof program is intentionally bounded. A diagram or happy-path list is not sufficient by itself.

## Governing doctrine

Preserve:

* author final authority
* manual truth mutation
* Narrative Insertion / Narrative Assertion as the smallest accepted manuscript-truth object
* scenes and chapters as projections or containers
* Writing Surface sovereignty
* Command Center non-sovereignty
* Companion non-ownership
* distributed ownership
* models perform tasks but do not own tools
* findings, Notes, Signals, candidates, memory, provenance, evidence, plans, projections, history, and accepted truth remain distinct
* analysis may be automatic; truth mutation remains manual

Do not:

* create a universal workflow engine
* create a universal approval state
* create a universal ready, complete, failed, blocked, or accepted state
* create a universal mode owner
* admit connectors
* treat job completion as destination acceptance
* turn recovery into truth ownership
* turn export or archive into truth mutation
* make Stage 9 GUI decisions
* make Stage 10 operational designs
* unblock implementation
* claim any workflow is already proved

## Cross-workflow risks

* Critique becoming Notes, Signals, rewrite execution, or truth owner
* Continuity becoming shadow canon
* candidate output entering manuscript truth without explicit acceptance
* preview state becoming accepted state
* route approval being confused with package approval or destination acceptance
* queue completion being confused with workflow success
* refusal being confused with application failure or manuscript defect
* fallback occurring without author approval
* Companion becoming a task or workflow owner
* restore becoming truth ownership
* export, archive, or backup becoming save or truth ownership
* provenance being lost during partial acceptance, fallback, recovery, or outward transfer
* partial results being presented as complete or current
