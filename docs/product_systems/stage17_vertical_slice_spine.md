## 3. Spine definition

The vertical slice spine is the ordered minimal flow proving:

1. Black Skies opens into a valid project context.
2. Project authority/truth identity is visible to the user.
3. The `Writing Surface` is present and usable.
4. The `Command Center` is present and usable.
5. A narrow manuscript/prose writing surface accepts writer work.
6. A narrow save-state/status flow is visible to the writer.
7. No excluded system is required for the slice to function.

This spine record is planning-only authority.

It does not authorize:

- coding
- runtime mutation
- test mutation
- witness creation or regeneration
- protected-evidence mutation
- cleanup/archive execution
